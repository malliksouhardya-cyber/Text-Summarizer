# 📚 Theory Question Analyzer

A Python-based tool that analyzes theory questions and helps identify important concepts, keywords, question patterns, and other useful information for study and examination preparation.

## 🚀 About the Project

**Theory Question Analyzer** is a Python project designed to make it easier to analyze theory-based questions.

The program takes a theory question as input and processes it to provide useful information about the question, such as its important keywords, topic/category, and other relevant analysis.

The project was created as a learning project to explore **Python, text processing, and basic Natural Language Processing (NLP)**.

### 1. Clone the repository


```bash

```

