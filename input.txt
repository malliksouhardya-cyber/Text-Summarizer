MODEL ANSWER:
A hash table is a data structure that maps keys to values using a hash function that computes an index into an array, allowing for efficient average-case $O(1)$ access, insertion, and deletion. It uses a hash function to convert an arbitrary key into a fixed-size integer index within the array bounds. Collision resolution strategies include chaining, where each array slot holds a linked list or tree of elements that hash to that index, and open addressing, where collisions are resolved by probing alternative slots using techniques like linear probing, quadratic probing, or double hashing. Average-case performance assumes uniform distribution and a load factor $\alpha = n/m$ maintained via dynamic resizing, while the worst-case time complexity is $O(n)$ when all keys hash to the same bucket.
